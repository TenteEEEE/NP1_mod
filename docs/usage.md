# 画面の使い方

## メニューと表示の切替

| 表示する端末 | メニュー |
| --- | --- |
| PC（既定） | 画面上部に、左右いっぱいに浮かぶメニューバー。幅に余裕があれば10画面をすべて並べます。幅が足りないときは、「設定」（純正設定・システム）、「ネットワーク」（4G・Wi-Fi / AP・Tailscale）、「ドラレコ」（ライブ・ドラレコ再生・走行履歴・ナンバー）の順に、まとまりごとに折りたたみます |
| PC（切替時） | 左側のサイドバー。10画面をすべて縦に並べます |
| スマートフォン（幅860px以下） | 上部に浮かぶタイトルバーと、下部の「ダッシュボード・ネットワーク・ドラレコ・設定」。ダッシュボード以外は、押すとその中の画面を選ぶメニューが開きます |

PCのメニューには、接続状態の右に3つのボタンが並びます。左から、メニュー位置の切替、ダッシュボードの概要／詳細の切替、状態の更新です。ダッシュボードの切替ボタンは、ほかの画面で押すとダッシュボードへ移動します。同じ切替は「システム › 設定・バックアップ › 表示設定」にもあります。スマートフォンでは、タイトルバーの右側に、ダッシュボードの概要／詳細の切替と状態の更新のボタンがあります。

ダッシュボードには2つの表示があります。

- **概要（既定）**: 現在地の地図を画面いっぱいの背景にし、その端に情報を配置します。
  - 左上: 走行の記録
  - 右上: 前方・車内のライブ映像
  - 下端: 同じ幅・同じ高さの4枚を、左から 4G データ通信、ネットワーク（Wi-Fi AP・Wi-Fi STA・Tailscale）、リソースモニター、本体の状態（稼働時間・Load average・SDカード・本体空き容量）の順に並べます

  ウィンドウの高さに合わせて、走行グラフとライブ映像の高さを調整します。

  幅がおよそ1280px未満のPCでは、上部に地図を見せ、その下を同じ幅の2列にします。走行の記録とライブ映像（前方・車内を横並び）を同じ高さで並べ、その下に4枚を2枚ずつ並べます。6枚をひとまとまりとして下寄せし、背の高い画面でも最下段の下に大きな空白を残しません。高さが足りない場合は縦にスクロールします。

  スマートフォンでは、地図が画面全体の背景になります。右上に前方カメラを小さく表示し（押すと「ライブ」を開きます）、そのほかの情報は下から引き出すパネルに入れています。パネルは上部のつまみを押すか、上下にドラッグして、小さく・半分・全面の3段階に切り替えます。内容をスクロールできるのは全面のときです。

  地図は現在地を中心に追従します。PCではマウスホイール、スマートフォンではピンチ操作で拡大・縮小でき、ドラッグで地図を移動できます。移動すると自動追従が止まり、地図右下の青い現在地矢印で再開します。ボタンと出典表示は地図の実際の右端から12pxに揃い、ボタンは出典表示の少し上にあります。緯度・経度（カンマ区切り）、衛星数、精度は、半透明で地図に重ねます。PCでは下段の4枚のすぐ上の左端（右端は地図の出典表示）、スマートフォンでは引き出しパネルのすぐ上の左端です。
- **詳細**: 概要で省いた項目も含めて、すべての情報を表示します。Wi-Fi APの動作、Wi-Fi STAの本日の通信量、Tailscaleのアカウントと通信経路、温度センサーごとの値などは詳細で確認できます。

メニュー位置とダッシュボードの表示は、操作しているブラウザーに保存します。本体には書き込まないため、PCとスマートフォンで別々に選べます。テーマ（ライト／ダーク）は従来どおり本体に保存します。

## ダッシュボードと走行履歴

以下は「詳細」表示の説明です。「概要」でも、走行の記録・ライブ映像・地図・4Gの操作は同じです。

ダッシュボードの「走行の記録」は、初期表示で7日を選択します。期間は24時間・7・30・90・365日、全期間、カスタムから選べます。24時間では現在時刻から過去24時間を1時間ごとの棒で表示し、横軸は「0・3・6・9…」の3時間刻みの時刻を数字だけで表示します。24時間以外は日・週・月で集計できます。棒グラフは各期間の値、折れ線は累計です。時間帯ごとの値は保存済みの観測区間を時間で按分しています。24時間の境界が観測区間の途中なら合計にも「約」が付きます。未観測の時間帯は0と区別します。

PCでは上段左に走行の記録、右に「GPS・録画」を配置します。4G・Wi-Fi AP・STA・Tailscaleは、その下の一列にまとめています。GPS・録画の上部には録画状態と保存済み件数を並べ、その下に前方・車内のJPEGライブ映像をカードの左右いっぱいに表示します。ライブ映像は約2秒に1回更新し、停止ボタン、画面外へのスクロール、別タブへの移動で取得を止めます。

地図はカードの横幅いっぱいに表示し、緯度・経度・衛星数・精度を地図上に重ねます。現在地と地図は、純正の画像認識が毎秒更新する位置を2秒ごとに取得して追従します。この位置を現在地として扱うのは、直近10分以内にGPSの測位記録があるか、位置が実際に動いているときだけです。衛星数と精度は、録画のクリップが閉じるたび（約3分ごと）に書かれるGPSの記録から取り、20秒より古い場合は「（2分前）」のように経過時間を添えます。測位できていないときは「測位できていません」と表示し、純正が把握している最後の位置を灰色の印（最後に分かっている位置）で示します。地図には過去24時間の走行経路を重ねます。録画中の判定はSD上の録画ファイルの更新から行い、停止から表示が変わるまで最大約25秒かかる場合があります。初回の更新確認中やSDの取得不能は、録画停止と区別して表示します。

下段左のリソースモニターでは4G・Wi-Fiを横並びにし、それぞれの上下速度、CPU・RAM・温度の現在値と推移を確認できます。温度はCPU・GPU・モデム・eMMCを色分けして重ねます。表示期間は5・15・60分です。推移はこの画面を開いている間の観測を使い、取得できなかった区間を0で埋めません。SDカードと本体容量は右側の「本体の状態」に残し、ラベルの横に残容量／全容量を表示します。稼働時間の下にはLoad average（1分・5分・15分）の現在値を表示します。モバイルでは各セクションを縦に並べます。

概要・詳細どちらのダッシュボードも、地図の経路は現在時刻からさかのぼる24時間です。0時では区切らず、1分ごととタブに戻ったときに更新します。グラフの初期選択は7日で、地図の経路の期間とは独立しています。

走行履歴は「走行の記録」「走行履歴マップ」「日別の詳細」の順に表示します。マップと詳細の日付は連動し、青い経路は録画に保存されたGPS測位から表示します。電波の記録や位置との紐づけがなくてもGPS経路を表示できます。「電波強度のヒートマップを表示」をオンにすると、その日の受信状態を重ねられます。電波の表示条件を変えてもGPS経路は消えません。「録画と地図」から、その走行の時刻をドラレコ再生で開けます。未測位や測位が途切れた区間には経路を補いません。距離の取得不能を0kmとは表示しません。

通常・イベント・駐車録画のGPSを読み取り、NCC側にも実測座標を保存するため、通常録画の上書き後も保存した点を表示できます。座標が一部しか残らない日も日別の距離・時間は保持し、欠測区間を線でつなぎません。11/13・11/14の回収結果は [過去2日分の経路とダッシュボードの修正](journey-days-and-dashboard-20261115.md) に記録しています。

電波観測の位置は、観測時刻と5秒以内のGPS測位に紐づけます。GPSのファイルは録画クリップの確定時に遅れて書かれるため、取得時は毎秒更新される位置を使い、直近15分は1分ごとに確定したGPS記録と再照合して保存します。古いGPSの精度を現在の位置の精度として流用しません。過去の紐づけ漏れを修復する手順は [走行履歴・地図の修正記録](journey-history-map-20261115.md) を参照してください。

純正のGPS記録はHDOPだけを持ち、メートル単位の精度を記録していない場合があります。この場合も電波の位置は色付き・破線の測定点として表示し、エリア集計には含めません。HDOPからメートル精度を作ることはありません。「精度不明の測定点も表示」をオフにすると、これらの点を隠せます。

## ドラレコ再生

1. カレンダーで録画のある日を選びます。
2. 時間バーの色が付いた区間をクリック・タップします。24時間・6時間・1時間・15分へ拡大でき、時刻の直接入力も可能です。
3. 前方・車内・並べて表示を切り替えます。並べて表示中の音声は主となるカメラから再生します。
4. タイムラインの下にある地図が再生時刻に追従します。経路や走行区間を選ぶと、その時刻に対応する録画へ移動します。

「録画設定」では前方と車内／後方を個別に「高画質 1080p」「長時間 720p」へ切り替え、録画に車内音声を含めるかを設定できます。保存済み録画の見出しには、計算できる場合に各カメラの平均映像ビットレートが表示されます。

録画も測位もある区間だけが連動します。時刻付近の位置記録がなければ、地図に現在位置の印を出しません。位置が記録されていない日も映像は再生できます。録画は原本H.264 / AACを使い、確定待ちのファイルは確定後に時間バーへ追加します。

## ライブ

ライブ画面で表示を開始します。H.264は純正エンコーダー直後の映像をWebRTCで受信するため、SDカードがなくても表示できます。純正録画サービスが停止している間は映像の再開を待ちます。前方・車内・並べて表示はドラレコ再生と共通です。JPEGプレビューも利用できます。ダッシュボードの「ライブ」の横のリンクからライブ画面へ、「録画中・件数」の横のリンクからドラレコ再生へ移動できます。

ライブのマイク音声には対応していません。保存済み録画の音声や、ブラウザーから本体へ送る共有音声とは別の機能です。

## ナンバー

前方カメラの映像から読み取ったナンバーを、場所と一緒に「記録」タブの一覧と地図へ表示します。一覧と地図の点は連動し、条件に合ったナンバーはオレンジで強調します。各記録の「録画を再生」で、検出した時刻の前方カメラの録画を画面上の小窓で再生します（最初に読んだ10秒前から、最後に読んだ10秒後まで）。小窓の「ドラレコ再生で開く」から、同じ時刻のドラレコ再生画面へ移れます。

「共有」では、利用者が設定したNumberShare APIへ検知をリアルタイム送信し、失敗時の自動再送・手動再送と状態確認を行えます。未設定時は、本人が決めた匿名ユーザーIDと運用者から配布された接続用キー（`DEVICE_API_KEY`）だけで初回登録できます。発行された機器用キー・端末ID・復旧情報は端末へ保存され、接続用キーは保存されません。管理画面用キーは初回登録とは別の任意設定です。開始日・終了日を指定すると、端末内に保存済みの検知を重複なくアップロードできます。この手動アップロードはリアルタイム送信が停止中でも実行されます。APIの履歴は受信専用の「APIから全件受信」で最終ページまで取得し、自分の検知をオレンジ、他の利用者を青として地図と一覧に分けて表示できます。ナンバー・照合状態・投稿範囲による履歴検索と、一連指定番号・地域／コメント・カテゴリによる登録車両検索も行えます。保存済みの機器用キーと管理画面用キーは通常は伏せ字で、表示設定を有効にしたときだけ平文表示します。「キーをコピーして管理画面を開く」は管理画面用キーをクリップボードへコピーして外部管理画面を新しいタブで開きます。

「条件と設定」で記録の有効化、保存日数・画像容量、条件（地名・分類番号・ひらがな・番号、`*`は任意の1文字）、読み上げのメッセージ（文字または音声ファイル）と声・音量を設定します。読み上げにはシステム › LED / 音声でVOICEVOX APIのキーを設定してください。詳細は [ナンバー認識と発話](plate-recognition.md) を参照してください。

前面LEDの「点灯」「消灯」は一時テストです。既定は5秒で自動消灯し、10秒・30秒も選べます。通常のプリセットは変更しません。常時点灯は「点灯し続ける」を明示的に選んだ場合だけ保存します。

## 4G・Wi-Fi・Tailscale

システム › 設定・バックアップの「純正ソフトウェアの更新抑止」に、更新を防ぐ各仕組み（取得の停止・削除防止・自動復旧・通信遮断・監視）の状態と警告を表示します。取得済みの更新データやSDカードの更新用ファイルが見つかった場合は、本体を再起動する前に確認してください。更新を許可する操作には確認があります（非推奨）。

同じ画面の「NP1 Control Center の更新」で、更新モードと利用回線を設定できます。「即時更新を実行」では、その場で更新を確認し、適用可能な新しい版があれば取り込みます。初回導入と各モードの動作は [NP1CCの自動更新](np1cc-auto-update.md) を参照してください。

4G画面は、回線の状態、通信量・月間上限、APN接続設定の順に並びます。キャリア、接続バンド、電波品質、通信量を確認します。通信量は本システムが記録した値で、Wi-Fiと4Gを分けて集計します。4Gの残量は設定した上限から記録分を引いた目安で、通信会社の請求データではありません。APNはプロファイルの編集・保存まで対応し、モデムへの実適用は未対応です。

Wi-Fi / AP画面の先頭の「インターネット回線」で、本体・純正アプリ・ホットスポットにつないだ端末が使う回線を選びます。「自動」は、Wi-Fiのリンクとデフォルト経路が3分間そろわないと4Gへ切り替えます。4Gの使用中は条件に応じて40秒間だけWi-Fiを試し、失敗後は間隔を空けて再試行します。「Wi-Fi」「4G」はその回線に固定します。純正サービスはWi-Fi接続（STA）がオンの間は4Gを使わないため、4Gへの切替は純正のSTAをオフにして行います。

自動モードで4Gを使用中も、「周辺を検索」やSSID入力からの接続を開始できます。本体が必要な間だけWi-Fiを起動し、検索だけの場合や接続を取り消した場合は元の4Gへ戻します。新しい接続を保存するには、IPv4アドレス取得後に「この接続を使う」を押してください。回線の切り替え中はTailscaleが一時的に切れることがあるため、NP1のホットスポットから開くと接続確認を続けられます。

Wi-Fi / AP画面にはSTAの接続先、ホットスポットのSSID・認証・DHCP、接続端末もまとめています。NCCに保存したWi-Fiパスワードとホットスポットのパスワードは入力欄へ読み戻し、通常は伏せ字、各「表示する」を選んだ場合だけ平文表示します。SSIDは常に通常の文字で表示します。ホットスポットにつないだ端末からは、この画面を http://192.168.226.1 で開けます。Tailscaleのアドレスや名前（`*.ts.net`）は、NP1がインターネットにつながっているときだけ使えます。

Tailscale画面ではアカウント・機器名・アドレス・接続状態を確認できます。機器名の変更もここで行います。管理画面はTailscaleのIPアドレスに加え、機器名（`<機器名>.<tailnet>.ts.net` と短い機器名）でも開けます。

## 純正設定・システム

MANAGE内の「純正設定」に、Alexa、運転サポート、ナビ・交通情報、案内・コエ、プライバシー、車両・取付をまとめています。Alexaは画面の先頭に表示します。取得できる値と変更できる項目は、ファームウェアと追加ヘルパーの有無で異なります。

システムには本体情報、ルーティング、SD、LED / 音声、USB、ログ、録画バックアップ、表示設定をまとめています。純正サービスの個別操作では、依存関係のために停止できない組み合わせがあります。SDはFIFO録画を前提とし、空き容量だけで警告しません。

LED / 音声の「音声合成（VOICEVOX API）」では、ナンバーと高度化PICSの読み上げに使うAPIのエンドポイントとキーを設定します。保存済みキーは入力欄へ読み戻し、通常は伏せ字、表示設定を有効にした場合だけ平文表示します。

「システム」の [高度化PICS](pics.md) では、受信記録を地図と一覧で確認できます。「受信・発話設定」では、ダッシュボードのライブ映像直下に出す信号の表示と、VOICEVOXの読み上げを切り替えられます。

LED / 音声の画面連動機能では、ブラウザーの画面共有から表示対象を選び、横方向の範囲の平均色を5つのLEDへ送ります。彩度・明るさ・コントラストを調整できます。音声共有に対応するブラウザーと共有対象では、本体への音声転送も選べます。画面共有にはHTTPS等のブラウザー側の利用条件があり、HTTP接続では利用できない場合があります。

## 純正アプリの本体操作

純正設定のAlexa直下の「本体の操作」で、SDカードの状態、録画・駐車監視・車両設定、取付情報を確認できます。「SDカードをフォーマット」はカード内の全データを消去するため、先に必要な録画等を保存してください。容量の確認、全消去へのチェックと確認文字の入力後に実行できます。確認は1分・1回だけ有効で、カード交換時は確認し直します。

本体操作は機能別カードのグリッドです。取付調整、リアウインドウ学習、GNSS、OSS・診断ログ転送、保守・シリアル、同期済みルートの案内、本体ログイン・チェックイン、純正Wi-Fi STA/APと初期化の操作をまとめています。認証情報は保存しません。保守には本体のキー操作、SD転送にはSDのマウント、ナビには同期済みルートが必要です。非対応の操作には理由を表示します。初期化・消去・接続の切替は、内容を確認してから実行してください。要求の受付と実際の動作完了は区別して表示します。

要求受付と完了は別に表示します。処理中はカードを抜いたり電源を切ったりせず、本体の音声案内で結果を確認してください。NCCが本体内に独立保存した走行履歴・設定を消す処理は含まれません。対応範囲・検証内容は [本体操作の記録](native-app-operations-20261116.md) を参照してください。

## 設定のバックアップ

システム › 設定・バックアップの「バックアップ」で、画面で設定した内容を1つのファイルに書き出し、復元できます。対象は、表示設定（テーマ・お気に入り・4Gの月間上限）、前面LED、ナンバー認識の条件と読み上げ（読み上げ用にアップロードした音声を含む）、VOICEVOXの接続先とAPIキー、録画のNASバックアップの接続先と対象、ホットスポット（SSID・パスワード・優先回線・自動起動）、NCCで追加したWi-Fi、APN、インターネット回線の切替、書き出したブラウザーの表示設定（メニュー位置・ダッシュボードの表示）です。ファイルにはパスワードやAPIキーが含まれるため、安全な場所に保管してください。

復元では、ファイルを選ぶと復元される項目の一覧を表示し、確認してから適用します。変更のあった項目だけを書き換え、関係するサービスを再起動します（30秒ほど画面がつながらないことがあります）。APNは保存のみで、本体への適用はAPN画面で行います。純正側に保存されたWi-Fiはパスワードを読み出せないため名前だけを記録し、復元しません。本体の自動更新の設定も記録のみで、復元しても有効には戻しません。以前の形式（表示設定のみ）のファイルも復元できます。

## 録画のNASバックアップ

システムの「録画バックアップ」で設定します。

- 常時録画と緊急録画は個別にON / OFFを設定します。
- 経路はWi-Fi STAまたはTailscaleを選び、それぞれにSMB・SFTP・WebDAVの接続方式と保存先を保持できます。
- 自動実行のタイミングはリアルタイム、または指定SSIDへの接続から選びます。
- 進捗の確認と中断・再開ができます。原本やNASの既存ファイルは削除せず、確定済みファイルを上書きしません。

初期状態では自動バックアップはOFFです。SDのFIFOで転送元が更新されると、そのファイルの転送を停止する場合があります。切断や本体再起動を含む復旧の通し検証は未完了です。
