# NP1CC 0.5.0 の実機導入記録

2026-11-22に、既存の標準導入済みNP1へ公開リリース `v0.5.0`（`fd75e06`）を適用した。導入には [NP1CCの自動更新](np1cc-auto-update.md) と [更新・復旧手順](recovery.md) の手順を使用した。

- リリースのEd25519署名と導入用ZIPのSHA-256を照合した。録画フック・注入器、ネイティブヘルパー、ナンバー認識エンジンおよびモデルなど、既存実機の27ファイルが配布物と一致したため、`web-worker-update` と `update-install` で適用した。
- 更新前のNP1CCバイナリは本体の `recovery/web-worker-*` とホスト側の非公開作業領域に退避した。導入後、永続領域と稼働中の各バイナリ、配布元、公開鍵を照合し、更新・復旧サービスの起動時有効化を確認した。
- HTTP/HTTPSのパスワード不要セッション、前方・車内カメラ、SD録画のMP4範囲読み出し、管理画面の更新設定を確認した。Communication、DriveRec、ImageRecog、Voice、QMMFは導入前後でプロセスとサービスの状態が一致した。実機ブラウザーテストは録画・走行履歴画面を含め、再実行で通過した。
- 自動更新は既定の「更新確認のみ」「Wi-Fiのみ」。実機の手動確認はWi-Fi経由でGitHubに接続できず、回線待ちを返した。設定は既定値のまま運用を開始した。
