# NumberShare接続用キー初回登録（2026-11-18）

## 目的

- NumberShare未設定時に、本人が決めた匿名ユーザーIDと運用者配布の `DEVICE_API_KEY` だけで端末用APIキーを取得できるようにする。
- 管理画面用キーを初回登録の前提にせず、管理機能を使う場合だけ別途設定できる状態を維持する。

## 実装

- 共有タブの初回登録欄は「匿名ユーザーID」「接続用キー（DEVICE_API_KEY）」の2値を受け取る。端末名はAPI送信時に `NP1` を補う。
- 接続用キーを `X-API-Key` としてNumberShareの `POST users` を呼び、応答した端末用APIキー、端末ID、復旧コードを端末の0600設定へ保存する。
- 接続用キー自体は保存しない。入力欄は既定で伏せ字にし、利用者が表示操作を選んだ場合だけ平文表示する。
- 発行された端末用APIキーで `GET users/me` を呼び、匿名IDと端末IDが登録応答と一致した場合だけ登録完了とする。
- 既に管理画面用キーを別途保存している場合は初回登録で消去しない。

## 検証項目

- 管理画面用キーなしで初回登録が成功すること。
- `POST users` が指定された接続用キー、匿名ユーザーID、既定端末名 `NP1` を受け取ること。
- 発行された端末用APIキーと復旧コードが保存され、接続用キーが保存されないこと。
- UIが管理画面用キーや端末名の入力を要求せず、接続用キーの伏せ字／表示切替を行えること。
