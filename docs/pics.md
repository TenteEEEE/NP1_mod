# 高度化PICSの実験機能

「システム › 設定・バックアップ › 高度化PICS」で設定します。初期状態では受信と表示がオン、VOICEVOXの発話がオフです。有効時はダッシュボードのライブ映像直下に、歩行者用信号の状態を表示します。複数方向の広告を受信したときは全信号を処理し、ダッシュボードでは青への推定時間が最も短い信号を優先します。設定画面には直近の受信候補も表示します。

発話をオンにすると、秒数の目安が初めて得られたときに「歩行者用信号、青まであとおよそ27秒です」、その後に「青まであとおよそ10秒です」と5から1までを案内します。赤から青への切り替わりはBLEの灯色情報を受信してから「歩行者用信号が青になりました」と知らせます。同時に切り替わった信号の案内はまとめます。本体スピーカーで再生する声と音量を設定し、操作画面から試聴できます。音声生成は共通のVOICEVOX設定を使い、定型文と数字を本体へ保存します。

参照実装が取得する1〜8の残り値は段階値です。NP1は交差点・灯器・段階ごとに、段階が1つ減った時点から青までの経過時間を観測します。直近5周期がそろい、最大と最小の差が2秒以内の場合に、中央値に基づく秒数を「目安」と表示します。初めて受信する信号や段階値のない信号では、受信した灯色と、観測できた赤から青への変化を利用できます。受信が途切れたり灯器を識別できなくなったりするとカウントダウンを終了します。観測値と受信履歴は本体のメモリーに保持します。 [参照実装の表示仕様](https://github.com/yumu19/ble-pics-viewer/blob/d97a27872ef1251a743fe8c1d5eadf0058e553a6/web/README.md#表示内容) [SIPモデル実証報告書 3.2.1](https://www.sip-adus.go.jp/file/154_s.pdf#page=27)

この実験機能の路上利用はNP1内蔵Bluetoothを前提としています。現在の受信実装はBlueZの共有LEスキャンに対応しています。確認したNP1ではBlueZとカーネルHCIが見つからず、純正の `NEventWatcherCom` がベンダーのBLEスタックを使用しています。純正BLEと共存する受信経路の確認が残っているため、該当個体では「BLE受信不可」と表示します。受信経路の確認には `tools/device/pics-receiver-preflight.sh` を使えます。
