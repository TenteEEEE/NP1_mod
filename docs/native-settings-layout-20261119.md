# 純正設定画面の整理（2026-11-19）

## 背景

`純正設定` には純正設定、保守操作、録画設定、音声設定、関連リンクが同じカードグリッドに混在していた。高さの異なるカードが同じ CSS Grid の行を共有するため、大きな空白が生じ、録画と音声の設定は `システム` 配下にも重複表示されていた。

## 再構成後の画面

- `純正設定`
  - `設定`
    - `本体`：Alexa、SDカード、車両・マイク、取付情報、アカウント状態、初期設定、取付チェック
    - `運転支援`：通知・検知
    - `ナビ・案内`：経路、交通情報、案内音声
    - `プライバシー・取付`：カメラ利用、取付情報
  - `操作・診断`
    - `調整・診断`：取付調整、GNSS・センサー、ライセンス・診断
    - `接続・アカウント`：ナビ操作、アカウント、純正Wi-Fi、純正ローカルAP
    - `保守・セットアップ`：保守、セットアップ、純正ファームウェア
  - `関連機能`：Control Centerまたは My NP1 の操作先
- `システム › 録画設定`
  - 通常録画
  - 駐車中の録画
  - H.264詳細録画設定
- `システム › LED / 音声`
  - 本体の音量
  - 消音・音量補正
  - LED、画面連動、録画音声の案内、音声合成

設定機能は削除せず、用途ごとに表示先を一意にした。画面上端の3区分と、区分内の用途タブで表示対象を絞るため、必要な機能へ直接移動できる。録画と音声の設定は `システム` 配下だけに置き、純正設定との重複を解消した。

アカウントカードは、見出しを「アカウント」、項目名を「ログイン状態」とし、取得値を独立した状態バッジで表示する。「ログイン済み」「未ログイン」「起動時の認証更新中」を色と文言の両方で区別し、項目名と現在値が連続した本文に見えないようにした。

基本設定と操作・診断のカードは、カード自体の高さを実測して CSS Grid の行スパンへ反映する。カードの高さを揃えるための空白は追加せず、列ごとに次のカードが直後へ配置される。CSS Columnsには変更していないため、表示順と操作順も維持する。

## 検証

- 320px / 390px / 1440px のモックAPI E2Eで、横スクロール、ページ例外、破壊的操作の誤送信がないことを確認する。
- 実機APIを読み取り専用で接続したPC / モバイルのスクリーンショットで、設定・操作・関連機能を確認する。
- 旧画面で約9,300pxあったデスクトップの一枚ページを、基本設定約1,500px、運転支援約800px、操作・診断約1,300pxなどの目的別画面へ分割した。
- 録画設定タブに通常録画・駐車録画・H.264設定が表示されることを確認する。
- LED / 音声タブに音量・消音・音量補正が表示され、現在音量の重複表示がないことを確認する。

全画面E2Eの実行中に、`available` かつ値が `null` のリソース観測でダッシュボードが例外終了する既存ケースも検出した。値がない観測は未取得として表示し、画面全体を失わないようにした。
