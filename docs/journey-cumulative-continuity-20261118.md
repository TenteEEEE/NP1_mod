# 走行グラフの累計線連続表示（2026-11-18）

## 変更内容

- 日別・週別・月別の集計区間に走行記録がない場合も、距離と走行時間の累計線を前区間の値で水平に継続する。
- 期間の途中だけでなく、最初の走行前は累計0、最後の走行後は最終累計値として線を期間端まで表示する。
- 各区間の棒は従来どおり、計測済み0と未計測を区別する。未計測区間の×表示や詳細欄の「—」を0へ置き換えない。
- 24時間表示も同じ考え方とし、走行のない時間帯では累計線だけを水平に維持する。

## 検証

- 集計ロジック試験で、未走行区間をまたいでも距離・時間の累計値が保持されることを確認した。
- 7日表示の累計SVGパスが1本の連続線になり、未計測日の前後で別パスへ分断されないことを確認した。
- 1440px / 320px、light / dark / systemの各表示で累計線、棒、未計測表示、キーボード操作、横幅を確認した。
